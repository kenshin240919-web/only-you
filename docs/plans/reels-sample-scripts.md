# 샘플 릴스 대본 4편 (2026-10-20, 2026-10-28 "추억" 중심 문구로 수정)

> 실제로 만들 때는 `docs/plans/reels-run.md`(Flow · 합치기 스크립트 · 업로드)를 따른다.

기획안 `docs/plans/instagram-plan.md`의 ③ 샘플 공개형. 사이트 샘플 곡을 그대로 쓰므로 ElevenLabs 크레딧이 들지 않는다.

## 공통 규칙

- 세로 9:16, **15~20초**. 첫 2초 안에 화면 글자(후킹)를 크게 띄운다.
- 음원: `public/samples/*.mp3` 그대로. **가사 첫 소절이 나오는 15초 구간**을 들어 보고 잘라 쓴다.
- 자막: 실제로 부른 가사를 큰 글씨로(한 줄씩). 마지막 2~3초는 말 캐릭터 + "프로필 링크에서 1분 만에".
- 정직하게: 샘플은 **가상의 이름과 사연**이다. 실제 반응처럼 보이는 문구("엄마가 울었다")는 쓰지 않고, 화면 구석에 작게 `예시 사연 · AI로 만든 노래`를 넣는다. 반응형 문구는 실제 반응 영상(①)에만 쓴다.
- 촬영 소스: 휴대폰 메모 앱에 사연 타이핑 화면 녹화, 사이트 `/samples` 화면 녹화, 직접 찍은 분위기 화면(부엌 불빛, 비 오는 골목 등). 편집은 CapCut 무료.
- 공통 캡션 끝: `프로필 링크에서 이름과 추억만 적으면 1분이면 완성돼요 🎤` + 해시태그 `#노래선물 #맞춤노래 #AI노래 #생일선물추천 #부모님선물 #기념일선물`

## 1편 · 엄마 「고마워요, 엄마」 (`mom.mp3`, 발라드 · 여성 보컬)

- **표지 글자**: "엄마한테 '고마워' 대신 노래를 보내면"

| 시간 | 화면 | 화면 글자 |
|---|---|---|
| 0~2초 | 메모 앱에 사연 타이핑: "새벽마다 부엌 불 켜고 도시락 싸 주던 엄마" | **이 한 줄로 노래를 만들었어요** |
| 2~4초 | 빠른 전환 + 시계 아이콘 | 1분 뒤 |
| 4~16초 | 새벽 부엌 불빛(직접 촬영) 위로 노래 | 새벽마다 켜져 있던 부엌 불빛 / 엄마의 하루는 늘 나보다 빨랐죠 |
| 16~19초 | 말 캐릭터 + 사이트 화면 | 엄마 이름 넣은 노래 · 프로필 링크 |

- **캡션 첫 줄**: 말로는 쑥스러운 "고마워", 노래로 대신 전해 보세요.

## 2편 · 연인 「Only You, 지은」 (`jieun.mp3`, 어쿠스틱 팝 · 남성 보컬)

- **표지 글자**: "우리 첫 데이트 추억으로 노래를 만들어 봤다"

| 시간 | 화면 | 화면 글자 |
|---|---|---|
| 0~2초 | 메모 앱: "비 오던 성수동, 우산 하나 같이 쓴 첫 데이트" | **우리 첫 데이트 추억으로 노래를 만들어 봤다** |
| 2~15초 | 비 오는 골목·우산(직접 촬영 또는 손만 나오는 커플 컷) | 비 오던 성수동 골목에서 / 우산 하나에 둘이 걷던 밤 |
| 15~18초 | 노래 제목 "Only You, 지은" 크게 → 말 캐릭터 | 우리만 아는 추억으로 만든 노래 |

- **캡션 첫 줄**: 기념일 선물 고민 끝. 둘만 아는 그날을 노래로.
- **시즌**: 빼빼로데이(11/11) 직전에 올리기 좋음. 표지를 "빼빼로 말고 이거"로 바꾼 버전도 만들 것.

## 3편 · 아빠 환갑 「아빠의 우산」 (`dad-umbrella.mp3`, 어쿠스틱 발라드 · 여성 보컬)

- **표지 글자**: "아빠 환갑 선물, 봉투 말고 이거"

| 시간 | 화면 | 화면 글자 |
|---|---|---|
| 0~2초 | 봉투를 내려놓는 손 → 휴대폰 | **아빠 환갑 선물, 봉투 말고 이거** |
| 2~14초 | 오래된 자전거·우산 소품 또는 가족 사진 앨범 넘기는 손(얼굴 없이) | 아빠, 오늘은 아빠의 예순 번째 봄이에요 / 어릴 적 제 자전거 뒤에서 아빠가 손을 잡아 주던 날 |
| 14~18초 | 말 캐릭터 | 아빠 이야기로 만든 단 한 곡 |

- **캡션 첫 줄**: 환갑·칠순 잔치에서 틀어 드리면 좋아요. 가사 카드로 액자처럼 남길 수도 있어요.

## 4편 · 자녀 응원 「괜찮아, 서준아」 (`seojun.mp3`, 밝은 팝 · 여성 보컬)

- **표지 글자**: "아이와의 추억으로 응원가를 만들어 봤어요"

| 시간 | 화면 | 화면 글자 |
|---|---|---|
| 0~2초 | 축구공·운동화(아이 얼굴 없이) | **아이와의 추억으로 응원가를 만들어 봤어요** |
| 2~14초 | 공 차는 발, 넘어졌다 일어나는 장면 느낌의 소품 컷 | 넘어져도 툭툭 털고 일어나는 / 멋진 우리 서준 |
| 14~18초 | 말 캐릭터 | 우리 아이만을 위한 응원가 |

- **캡션 첫 줄**: 시합 전날, 시험 전날, 아이에게 들려주세요.
- **시즌**: 수능 응원(11월) 버전은 표지를 "수능 보는 동생한테 이름 넣은 응원가"로. 단, 실제 수능 응원 곡은 따로 만들어야 하므로(크레딧 1곡) 만들기 전에 결정.
